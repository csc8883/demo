你现在接手的是一个电力杆塔点云航点规划系统。请基于现有代码进行“电力专用语义-几何建模 + 现有禁飞区系统融合”升级。注意：不要重写整个系统，不要破坏现有前端可视化、体素文件读取、候选航点 JSON、航线规划器和禁飞体加载逻辑。

当前系统已经存在以下关键能力：

1. 前端点击“点云栅格化”后，调用 POST /api/process/voxelize。
2. 后端 main.py 中会构造 Pretreatment 实例，并调用 waypoint_planning/algorithms.py 中 Pretreatment.run()。
3. Pretreatment.run() 会读取 LAS 点云，得到：
   - points: shape = (N, 3)
   - labels: shape = (N,)
4. 点云分类标签为：
   - 16：杆塔本体 tower
   - 22：绝缘子 insulator
   - 0：导线 conductor
   - 3：地线 ground_wire
5. 当前体素化核心函数是 waypoint_planning/planning_core.py 中：
   - build_semantic_surface_model(points, labels, voxel_size=0.10)
6. 当前候选视点生成函数是：
   - generate_candidate_views(surface_model)
7. 当前输出文件包括：
   - userdata/{username}/voxel/{base}_voxel.npz
   - userdata/{username}/voxel/{base}_candidates.json
8. 当前 .npz 中已有字段：
   - min_bound
   - voxel_size
   - z_max_map
   - voxels
   - attention_targets
   - display_voxels
   - conductor_no_fly_volumes
   - safety_points
   - safety_labels
   - local_center
   - meta_json
9. 当前系统已有 ConductorNoFlyVolume 禁飞体系统。它不是普通包围盒，而是沿导线-地线空间分布构建的定向棱柱体。它已经用于候选视点过滤、航段穿越检测、A* 局部绕行、航点安全修正。因此禁止用新的 wire safety tube 替代它。

本次任务目标：

在不破坏现有架构的前提下，把当前“语义表面体素模型”升级为“电力专用语义-几何可见性模型”，并把现有 ConductorNoFlyVolume 作为最高优先级安全约束整合进候选视点生成与后续可见性/覆盖率数据结构中。

核心原则：

1. 只增强，不推翻。
2. 旧字段必须保留，新字段可以新增。
3. ConductorNoFlyVolume 是最高优先级安全模型。
4. wire_curves / safety_tubes 只能作为辅助几何模型，用于导线/地线细粒度表达、局部距离分析、视觉遮挡判断，以及禁飞体缺失时的 fallback。
5. 不允许把 safety_distance_m 写死为 3.0m。应优先读取 API / 用户输入参数，其次读取 DEFAULT_LIMITS["safety_distance_m"]，最后才使用 fallback。
6. 不允许把 no-fly volume 当作视觉遮挡体。禁飞体用于飞行安全；视觉遮挡应由 tower/insulator 几何体、voxel 占据模型、wire_curves 的 occ_radius 判断。
7. 不能让新增逻辑导致栅格化任务失败。导线不足、绝缘子聚类失败、PCA 失败、候选点过少时都必须有 fallback。

其中：

   - 每个 tower patch 增加 layer_id、sector_id、radial_normal、area、weight、min_dist、max_dist、max_view_angle_deg。
   - 用于后续计算塔身分层、分方位覆盖率。

2. 绝缘子 insulator：
   - 不能只按全局 semantic + 方位 + 高度聚合。
   - 必须按绝缘子串实例建模。
   - 对每个绝缘子 cluster 拟合 PCA axis、center、length、radius、bbox。
   - 对每串绝缘子按 axis 分段，并按环向方向生成高权重目标 cell / patch。
   - insulator patch 聚合 key 必须包含 insulator_instance_id，避免不同绝缘子串混合。

3. 导线 conductor / 地线 ground_wire：
   - 继续保留 display_voxels。
   - 继续保留 conductor_no_fly_volumes。
   - 新增 wire_curves：polyline + occ_radius + safety_radius。
   - wire_curves 不替代 no-fly volume，只作为辅助几何模型。

4. 禁飞区 no-fly：
   - ConductorNoFlyVolume 是主安全模型。
   - 候选视点必须优先通过 contains() 和 clearance() 过滤。
   - 航段安全仍交给 route_planner 的 segment_intersects / A* / detour 逻辑。
   - voxelize 阶段只保证候选点安全，不要试图替代航段绕行。

5. 候选视点 candidates：
   - 保留当前多距离、多高度偏移、多焦段、多 yaw 偏移机制。
   - 按语义目标分流生成：
     a. tower：沿 radial_normal 外扩。
     b. insulator：沿 outward / ±line_direction / ±z_axis 多角度生成。
     c. connection targets：生成斜侧视点，避免落入禁飞体。
   - 每个候选视点新增 target_id、semantic、instance_id、layer_id、sector_id、weight、required_gsd、max_view_angle_deg、no_fly_checked、no_fly_clearance_m 等字段。
   - 旧字段必须保留。

6. 覆盖率数据结构：
   - 为后续支持 weighted_coverage 做准备：
     weighted_coverage = sum(weight_i * area_i * covered_i) / sum(weight_i * area_i)
   - 每个 target patch / voxel 至少应支持：
     id, pos, semantic, label, category, weight, area, normal, normal_hint, is_planning_target, min_dist, max_dist, max_view_angle_deg, required_gsd, instance_id, layer_id, sector_id, source

- candidate.position = patch.pos + normal * distance + z_axis * height_offset。
- yaw / pitch 指向 patch.pos。
- weight 使用 patch.weight。
- target_id = patch.id。
- layer_id / sector_id 继承 patch。

建议距离：

- tower_body: 7m / 10m / 13m
- tower_edge: 6m / 9m / 12m
- tower_top: 8m / 12m / 16m
- tower_lower30: 7m / 10m / 13m

保留原有焦段 F0/F1/F2 和 yaw offset。

--------------------------------------------------
6.2 insulator 专用候选视点
--------------------------------------------------

对 insulator patch / target cell：

必须生成专用视点，不要只依赖全塔环绕点。

使用：
- insulator_instance.center
- insulator_instance.axis
- local_frame.x_axis 作为 line_direction
- local_frame.z_axis
- tower center 到 insulator center 的 outward direction

每串绝缘子至少生成以下方向：

1. outward 正视
2. normalize(0.8 * outward + 0.4 * line_direction)
3. normalize(0.8 * outward - 0.4 * line_direction)
4. normalize(0.8 * outward + 0.3 * z_axis)
5. normalize(0.8 * outward - 0.3 * z_axis)

距离建议：

- 4.5m
- 6.0m
- 7.5m

每个 candidate：
- semantic = "insulator"
- instance_id = insulator_instance_id
- target_id = patch.id
- weight = patch.weight or 5.0
- max_view_angle_deg = 55.0
- pitch / yaw 指向 insulator cell 或 instance center

绝缘子候选点必须特殊处理禁飞体：

1. 先生成原始 candidate。
2. 检查 no-fly volume.contains(position)。
3. 如果落入禁飞体，不要立即放弃，先尝试修正：
   - 沿远离禁飞体中心方向外推；
   - 或沿 no_fly_volume.v_axis 的外侧方向外推；
   - 或沿 z_axis 小幅调整。
4. 每次步长 0.5m，最多尝试 6 次。
5. 修正后仍 contains()，则丢弃。
6. 如果 clearance < required_clearance，继续外推直到满足或达到最大尝试次数。
7. candidate 中记录：

{
  "adjusted_for_no_fly": true/false,
  "adjustment_steps": int,
  "original_position": [x, y, z] or null
}

注意：
- 不能把绝缘子候选视点推到导线-地线之间。
- wire_insulator_connection 宁可生成更多斜侧视点，也不要在禁飞体内部生成正视点。

--------------------------------------------------
6.3 connection attention target 候选视点
--------------------------------------------------

对 wire_insulator_connection：

- 权重最高，建议 6.0。
- 候选点必须在禁飞体外。
- 如果正视点被禁飞体过滤，应自动生成两侧斜视点。
- 斜视方向优先沿 no_fly_volume.v_axis 外侧偏移。
- 额外增加沿 line_direction 两侧的斜视点。
- 目标方向指向 connection target。

对 ground_wire_tower_connection：

- 权重 4.5。
- 候选点容易靠近地线和禁飞体上界。
- 候选点应优先从禁飞体外侧和略高于目标处观察。
- 必须检查 clearance。

对 tower_base_connection：

- 权重 2.0。
- 通常不受导线禁飞体影响，但仍走统一 no-fly filter。

--------------------------------------------------
6.4 统一候选视点安全过滤
--------------------------------------------------

请新增统一函数，例如：

filter_candidate_by_safety(candidate, surface_model, limits, allow_adjust=False)

逻辑：

1. 读取 no_fly_volumes：
   - surface_model["conductor_no_fly_volumes"]
   - 或 surface_model["no_fly_volumes"]
   - 保持兼容现有字段名。

2. 读取安全参数：
   - safety_distance_m
   - conductor_no_fly_exterior_clearance_m
   - tower_safety_radius

3. required_clearance = max(
      safety_distance_m,
      conductor_no_fly_exterior_clearance_m
   )

4. 对每个 no_fly_volume：

   a. 如果 volume.contains(candidate.position) 为 True：
      - 如果 allow_adjust=True，尝试外推修正。
      - 如果修正失败，丢弃。
      - 如果 allow_adjust=False，直接丢弃。
      - contains() 内部永远不能保留。

   b. clearance = volume.clearance(candidate.position)
      - 如果 clearance < required_clearance：
        - 如果 allow_adjust=True，尝试外推修正。
        - 如果修正失败，丢弃或进入 fallback relaxed clearance。
      - 记录最小 no_fly_clearance_m。

5. fallback relaxed clearance：
   - 如果严格过滤后候选点过少，例如 final_count < raw_count * 0.10 或 final_count < 20：
     - 可以放宽 required_clearance 到 safety_distance_m。
     - 但仍然禁止 contains() 内部点。
     - 必须在 meta_json 中记录 warning：
       "fallback_relaxed_clearance_used": true

6. wire_curves 辅助检查：
   - 如果 no_fly_volumes 不存在，wire_curves 的 safety_radius 作为主安全约束。
   - 如果 no_fly_volumes 存在，wire_curves 只做补充，避免局部贴近导线。
   - 到 wire_curves 的距离小于 safety_radius 时，候选点丢弃或修正。
   - safety_radius 默认读取 safety_distance_m。

7. 塔体安全距离：
   - 使用 safety_points / safety_labels。
   - 候选点到 tower / insulator 物理点距离小于 tower_safety_radius 时丢弃。
   - tower_safety_radius 默认 2.0m，独立于 conductor no-fly safety_distance_m。

8. 每个 candidate 新增字段：

{
  "no_fly_checked": true,
  "no_fly_inside": false,
  "no_fly_clearance_m": float or null,
  "no_fly_required_clearance_m": float,
  "safety_filter_source": "conductor_no_fly_volume" or "wire_curve_fallback" or "none",
  "safety_checked": true,
  "safety_warning": null or string
}

==================================================
八、飞行安全与视觉遮挡必须区分
==================================================

请明确区分：

1. 飞行安全约束：
   - 候选点不能在 no-fly volume 内。
   - 候选点到 no-fly volume 的 clearance 不能小于 required_clearance。
   - 航段不能穿越 no-fly volume。
   - 航段 clearance 不能小于 route planner 的 no-fly margin。
   - 这是强约束。

2. 视觉可见性约束：
   - 相机到目标的视线穿过 no-fly volume，不一定代表无人机进入禁飞区。
   - 因此不要简单把“视线穿过禁飞体”判定为不可见。
   - 视觉遮挡应由：
     a. 杆塔/绝缘子 voxel 或 mesh
     b. wire_curves 的 occ_radius
     c. 其他物理几何体
     来判断。

所以：
- no_fly_volume 用于候选点和航段安全。
- wire_curves occ_radius 用于导线/地线视觉遮挡。
- tower / insulator voxel occupancy 用于结构遮挡。
- 不要把 no_fly_volume 当作大遮挡体。

十一、鲁棒性和回退策略
==================================================

必须实现以下 fallback：

1. 导线点不足：
   - local_frame.x_axis 使用杆塔 XY PCA fallback。
   - wire_curves 为空或 fallback。
   - 系统不能崩。

2. conductor_no_fly_volumes 不存在：
   - 尝试从 display_voxels 中导线/地线重新构建。
   - 若仍失败，wire_curves safety_radius 作为候选视点安全 fallback。
   - meta_json 写入 warning。

3. 绝缘子聚类失败：
   - 将全部绝缘子点作为一个 insulator instance。
   - 或退回 legacy insulator patch 逻辑。
   - 系统不能崩。

4. PCA 失败：
   - 使用 bbox 主方向。
   - 再失败使用 local_frame.x_axis。
   - 不能让任务失败。

5. 新增字段缺失：
   - generate_candidate_views 必须使用旧字段 fallback。

6. 候选点过少：
   - 如果严格 no-fly clearance 过滤后候选数量过少，可以放宽 clearance 到 safety_distance_m。
   - 但 contains() 内部永远禁止。
   - meta_json 记录 warning。

7. 保存 .npz 失败：
   - 如果新增 object 字段无法序列化，复杂新增信息转存 meta_json。
   - 原有字段必须继续保存。

最终目标：
